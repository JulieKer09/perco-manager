# Perco Manager v1.0.0

Premiere version partageable de l'application.

## Nouveautes
- Application desktop Electron packagée pour Windows.
- Connexion Discord (session utilisateur).
- Donnees des percepteurs et recoltes rattachees au compte Discord connecte.
- Widget integre et synchronise avec l'application principale.
- Ecran de connexion personnalise.
- Icone application personnalisee.

## Installation
1. Telecharger le fichier Perco Dofus Setup 1.0.0.exe.
2. Lancer l'installateur.
3. Ouvrir l'application puis cliquer sur Connexion.
4. Autoriser la connexion Discord.

## Important
- A la premiere installation, Windows SmartScreen peut afficher un avertissement car l'application n'est pas signee avec un certificat editeur payant.
- Si vous voyez cet avertissement, cliquer sur Informations complementaires puis Executer quand meme.

## Prerequis
- Windows 10 ou Windows 11.
- Connexion internet pour l'authentification Discord.
